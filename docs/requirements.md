# Требования

- TECH-01: Java 21, Spring Boot, Maven, PostgreSQL, Hibernate, Lombok, MapStruct, JUnit и Mockito.
- RUN-01: запуск приложения и PostgreSQL через Docker Compose.
- CFG-01: конфигурация через переменные окружения, без секретов в Git.
- QA-01: unit-тесты расчётов и интеграционные проверки на PostgreSQL.
- DOC-01: README описывает запуск, тесты и конфигурацию.
- TIME-01: часовой пояс и часы приложения настраиваются и тестируются.

Бизнес-требования складского MVP перенесены в рабочую записку до реализации соответствующих шагов.
