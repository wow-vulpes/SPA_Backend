# Демонстрационный сценарий

Обычный `docker compose up` включает APP_DEMO_ENABLED=true. Без Compose
загрузчик выключен по умолчанию; в IDE можно явно включить эту переменную.
Приложение загружает demo только если все шесть предметных таблиц пусты.
Миграция Flyway создаёт схему отдельно от demo.

Загрузка атомарна: справочники и все движения либо сохраняются вместе,
либо откатываются. Движения проходят через MovementService, включая FEFO,
проверку остатков и хронологии. Блокировка таблиц сериализует первоначальную
загрузку. При непустой базе загрузчик пропускает загрузку целиком, ничего не
удаляет и не добавляет. Повторный запуск не дублирует и не освежает данные.

## Набор данных

Все имена и цены синтетические, валюта RUB. Даты относительно бизнес-даты D
**первой загрузки**, а не каждого запуска. Через несколько дней расход за
90 дней, сроки и предупреждения закономерно изменятся.

4 товара, 2 объекта, 5 позиций, 6 партий, 101 движение и 101 распределение.

| SKU | Объект | Физический / доступный остаток в день D | Сценарий |
| --- | --- | --- | --- |
| DEMO-OIL | DEMO-CENTER | 20 / 20 bottle | 90 ежедневных расходов по 1; две партии с остатками по 10, первая истекает D+10; дефицит на 30 дней |
| DEMO-OIL | DEMO-NORTH | 99 / 99 bottle | Отдельный объект, другой расход и цена |
| DEMO-MASK | DEMO-CENTER | 5 / 0 pcs | Срок D−1, последняя операция D−100: просрочка и отсутствие движения |
| DEMO-SALT | DEMO-CENTER | 40 / 40 kg | Нет движения 100 дней, срок D+365 |
| DEMO-TOWEL | DEMO-CENTER | 90 / 90 pcs | Приход 100, расход 10, возврат 2, списание 1, коррекция −1 |

В OIL-CENTER сначала поступают 100 по 200 RUB (D−100), затем 10 по 250 RUB
(D−95). 90 расходов за D−90…D−1 используют раннюю партию. Последняя цена
поступления — 250 RUB. При стандартных порогах /alerts вернёт 5 предупреждений:
SHORTAGE масла, EXPIRING ранней партии масла, EXPIRED маски и два NO_MOVEMENT.

## Просмотр и расчёт

После готовности приложения:

```bash
curl --fail 'http://localhost:8080/api/stock?sku=DEMO-OIL&location=DEMO-CENTER'
curl --fail 'http://localhost:8080/api/alerts'
curl --fail http://localhost:8080/api/forecast \
  -H 'Content-Type: application/json' \
  -d '{"sku":"DEMO-OIL","location":"DEMO-CENTER","horizon_months":1,"lead_time_days":3,"safety_days":5,"minimum_order_quantity":0,"pack_size":10}'
```

В день загрузки средний расход 1 bottle/день, доступно 20, запас 20 дней.
Прогноз заказа на календарный месяц: 20 bottle с упаковкой 10, стоимость
5000 RUB. Точное количество дней месяца зависит от D. Прогноз читает данные,
но не размещает заказ. Истечение партий дополнительно проверяется календарно.

Партии: `GET /api/stock/DEMO-OIL`.
История: `GET /api/movements?sku=DEMO-OIL&location=DEMO-CENTER&type=consume`.

## Повторяемая HTTP-проверка

На свежем неизменённом demo со стандартными порогами, в день его загрузки:

```bash
python3 scripts/demo-smoke.py
```

Используется только стандартная библиотека Python 3. Проверяются health,
остатки, партии, история, все типы предупреждений и прогноз. Для другого
порта передайте `--url http://localhost:18080`. Скрипт выводит длительность
каждого запроса и не пишет движения/заказы. Это функциональная проверка
малого набора, не нагрузочный тест и не доказательство качества прогноза.

Интеграционный DemoApiIT дополнительно проводит расход 11: FEFO списывает
10 из ранней и 1 из поздней партии, остаток становится 9. Повтор того же
документа даёт 409, расход 1000 — 422 без изменения данных. Это выполняется
только на временной тестовой PostgreSQL, не на пользовательской базе.

## Сохранение и новый demo

`docker compose down` сохраняет данные; следующий `up` использует их.
APP_DEMO_ENABLED=false отключает только загрузку, не удаляет существующий demo.
При уже заполненной базе demo не подмешивается. Для нового demo используйте
новое имя проекта Compose: оно создаст отдельный том. Сначала остановите
предыдущий экземпляр или выберите свободный порт:

```bash
APP_PORT=18080 docker compose -p spa-demo-fresh up
```

Имя spa-demo-fresh должно быть новым: повторное использование имени сохраняет
ранее загруженные данные. Старые тома не удаляйте без необходимости.
Старая схема V1/V2 требует отдельного перехода: [migrations.md](migrations.md).
